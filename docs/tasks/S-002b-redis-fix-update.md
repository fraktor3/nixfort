# S-002b — Обновление контроллера: исправление Redis + версия T-006…T-008 (выполняет Cursor)

| Поле | Значение |
|---|---|
| Причина | Ошибка 500 при «Тестовом задании»: Redis в protected mode без пароля отвергал соединения из других контейнеров (`lab/reports/S-002-error500.md`). Исправлено в ADR-026…029 |
| Код | не менять |

## Шаги (nx-controller, `~/nixfort`)
1. `git pull` — должен прийти коммит с T-006…T-008 и исправлением Redis.
2. `python3 deploy/gen-env.py` — допишет `REDIS_PASSWORD` в существующий `.env` (вывод: `added REDIS_PASSWORD to existing .env`). Старую строку `REDIS_URL` в `.env` можно не трогать: compose её переопределяет.
3. `make up` (пересборка образа) → `make ps`: postgres/redis/web healthy.
4. **`make selfcheck`** — все строки `[OK]`, «ИТОГ: всё в порядке» дважды (web и worker-mutation). Если есть `[FAIL]` — остановиться и прислать вывод.
5. `make itest` — число passed (ожидается ≥ 340).
6. Сообщить руководителю: можно повторить «Тестовое задание» в браузере (ожидается «Успешно» за 5–10 с).
7. Дописать в `lab/reports/S-002-<дата>.md` раздел «Ошибка 500: причина и исправление» с выводом `make selfcheck`.

После этого продолжается шаг 8 карточки S-002. Ключи узлов теперь можно получать кнопкой **«Получить ключ с узла»** в карточке узла (узел должен быть запущен, не на паузе); подтверждает руководитель после сверки отпечатка.
