# T-000 — Испытательный стенд (выполняет руководитель)

| Поле | Значение |
|---|---|
| Приоритет | P1 |
| Исполнитель | человек |
| Читать | `docs/LAB_SETUP.md` |

## Цель
4 ВМ в VirtualBox в изолированных сетях, трафик users↔servers проходит через шлюз.

## Критерии готовности
- [ ] 4 ВМ с уникальными host key и machine-id.
- [ ] Адреса по таблице `PROJECT_CONTEXT.md`.
- [ ] `ip route get 10.99.0.10` на клиенте → via 10.88.0.1; tcpdump на шлюзе видит трафик клиент→сервер.
- [ ] На nx-server работают nginx:80 и lab-extra:8080.
- [ ] На nx-controller работает `docker compose version`.
- [ ] Снапшоты `clean-base` у всех ВМ.
- [ ] Вывод проверок отправлен архитектору.
