## Цель
Проверить на реальных ВМ: подключение контроллера к агентам из веб-интерфейса, инвентаризацию, Nmap и аудит по 21 проверке.

## Шаги
1. На nx-controller: `cd ~/nixfort && git pull && make up` (пересборка), `make ps` — всё healthy. `make itest` — все тесты passed (ожидается ≥ 341, 2 skipped).
2. В интерфейсе на каждом узле: удалить вставленный вручную ключ не нужно — нажать **«Получить ключ с узла»**, дождаться задания. Если отпечаток совпадает с прежним, ключ остаётся подтверждённым; если нет — сверить с `lab/reports/S-001-*.md` и подтвердить (это делает руководитель).
3. На странице проекта — **«Инвентаризация всех узлов»**. Ожидается SUCCEEDED; в карточке каждого узла — факты (ОС, интерфейсы, пакеты, службы, порты, SSH).
4. **«Сканирование» → «Типовые порты»**. Ожидается: 10.77.0.20 → 22; 10.77.0.30 → 22, 80, 8080; 10.77.0.40 → 22.
5. **«Аудит» → «Запустить аудит»**. Ожидаемая матрица (исходное состояние стенда):
   - nx-server: SYS-01..03 PASS, **SYS-04 FAIL (8080)**, SSH-01 FAIL, SSH-02 FAIL, SSH-03 PASS, SSH-04 FAIL, SSH-05 FAIL, SSH-06 FAIL, SSH-07 PASS, F2B-01..03 FAIL;
   - nx-gateway: SYS-01..04 PASS, SSH как у сервера, FW-01 PASS, FW-02 FAIL (политика активна, таблицы нет), FW-03 FAIL, FW-04 NOT_APPLICABLE, IDS-01..03 FAIL.
   Любое отличие — записать (с открытой страницей результата проверки).
6. Негатив:
   - выключить nx-client или остановить на nx-server ssh (`sudo systemctl stop ssh ssh.socket`) → инвентаризация узла → статус узла «Недоступен», аудит по нему → ERROR, **не PASS**; вернуть ssh (`sudo systemctl start ssh.socket`);
   - на nx-server перегенерировать ключ (`sudo rm /etc/ssh/ssh_host_ed25519_key* && sudo dpkg-reconfigure openssh-server`) → инвентаризация → ошибка `host_key_mismatch`, запись «Несовпадение ключа узла» в журнале; затем «Получить ключ», сверить новый отпечаток на узле (`ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`) и подтвердить;
   - под наблюдателем: кнопок запуска нет, POST на запуск аудита → 403.
7. Скриншоты: матрица аудита, карточка узла с фактами, результат проверки SSH-01 с доказательством, сканирование — в `lab/reports/S-003/`.
