# S-010 — Приёмочные испытания с чистого стенда (Cursor + руководитель)

| Поле | Значение |
|---|---|
| Зависит от | S-009 принята; всё запушено |
| Код | **не менять** `app/`, `agent/`, `deploy/`, `lab/inject_defects.sh`. Ошибка или расхождение — полный вывод в отчёт и **остановка** |
| Читать | `docs/TESTING.md` §2 (AT-01…AT-26), `AGENTS.md` §7, отчёты S-001, S-002, S-004, S-005, S-009 (там уже отработанные ручные процедуры) |
| Итог | `lab/reports/S-010-<дата>.md` — **протокол испытаний** (пойдёт в ВКР) + скриншоты `lab/reports/S-010/` |

**Что это.** Вся система проверяется заново, начиная с чистых ВМ: установка, модель стенда, аудит внесённых дефектов, исправление, проверка защиты, отказоустойчивость, отчёт. Это доказательство работоспособности для ВКР, поэтому важна точность: ожидалось / получено / время / скриншот.

**Как работать.** Карточка длинная — делать **по частям**, после каждой части короткий промежуточный отчёт руководителю и остановка: «Часть N готова». Веб-интерфейс — под `cursor` (`AGENTS.md` §7). Шаги с пометкой **[руководитель]** делает только руководитель: остановись и напиши, что нужно сделать. Пароли нигде не записывать.

**Формат протокола** (для каждого AT):
```
### AT-xx — <название>
Время: 27.10.2026 16:05–16:12 UTC · коммит: <hash> · агент 1.6.0
Шаги: 1) … 2) …
Ожидалось: …
Получено: … (цифры, состояния, ID заданий)
Итог: ПРОЙДЕН / НЕ ПРОЙДЕН / ЧАСТИЧНО (почему)
Доказательства: lab/reports/S-010/at-xx-*.webp
```

## Часть 0 — подготовка (Cursor)
1. Снимок всех четырёх ВМ **`lab-s009-done`** (страховка: туда можно вернуться).
2. **nx-gateway, nx-server, nx-client** — выключить, восстановить снимок **`clean-base`**, включить. **nx-controller не восстанавливать.**
3. Проверить чистоту (только чтение): на трёх узлах `id nixfort` → «no such user»; на сервере `ls /etc/ssh/sshd_config.d/`, `dpkg -l fail2ban 2>/dev/null | grep ^ii` (пусто), `systemctl is-active lab-extra nginx`; на шлюзе `sudo nft list tables` (нет `inet nixfort`), `dpkg -l suricata 2>/dev/null | grep ^ii` (пусто). Отпечатки host key трёх узлов сверить со значениями из `lab/reports/S-008-2026-10-27.md` (снимок тот же — должны совпасть).
4. На nx-controller: `cd ~/nixfort && git pull` → записать хеш коммита (`git log -1 --oneline`).

## Часть A — чистая установка контроллера (AT-01)

Записать: `make ps` (все healthy/running), `docker compose exec web id` (uid 10001), `curl -sk https://127.0.0.1/healthz` (`{"status": "ok"}`), `curl -sI http://127.0.0.1/` (301 на https), `make selfcheck` (без `[FAIL]`), `make itest` (**445 passed, 5 skipped, 0 failed**).

8. **[руководитель]** `make createadmin` (свой логин и пароль), вход в веб. Создать пользователей: **`cursor`** (администратор, новый пароль — передать Cursor отдельным сообщением) и **`viewer1`** (наблюдатель). Пароли Cursor не нужны, кроме своего.
