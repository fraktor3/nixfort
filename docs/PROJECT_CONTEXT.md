# NIXFORT — контекст проекта (читать первым)

## Что это
**NIXFORT** — self-hosted веб-приложение для аудита, контролируемого усиления и доказательной проверки безопасности небольшого сегмента сети на Linux. Выпускная квалификационная работа (ВКР) по информационной безопасности.

Тема ВКР: «Разработка веб-приложения, предназначенного для построения комплексной системы защиты сети, функционирующей под управлением ОС семейства Linux».

## Суть одной фразой
Приложение находит проблемы безопасности в Linux-сети, **безопасно** их исправляет из фиксированного набора мер и **доказывает проверкой**, что защита сработала и нужные соединения не сломались.

## Главный цикл (ядро продукта)
```
Модель сети → Инвентаризация → Аудит (проверки) → План исправления → Подтверждение
 → Снимок + таймер автоотката на узле → Применение → Постпроверка (конфиг + реальные соединения)
 → Фиксация ИЛИ автооткат → Отчёт «до/после» с доказательствами
```

## Состав (версия, сдаваемая к защите)
- Вход, роли: Администратор / Оператор / Наблюдатель. Журнал действий.
- Проекты, узлы (роли: gateway, server, ids_sensor, test_client), политика соединений (allow/deny TCP).
- Узловой агент `nixfort-agent` (SSH forced command, только фиксированные действия).
- Инвентаризация + Nmap (`-sT`, только разрешённые адреса).
- 21 проверка: SYS ×4, SSH ×7, FW ×4, F2B ×3, IDS ×3 (`docs/CHECKS_CATALOG.md`).
- Исправления: установка средств защиты (fail2ban/suricata/nftables из allowlist), профиль Fail2ban, профиль SSH, политика nftables на шлюзе, профиль датчика Suricata.
- Постпроверки: TCP-пробы allow/deny с тестового клиента до/после, автооткат по таймеру на узле.
- Suricata: статус, события EVE, тестовое событие. PCAP-анализ через TShark (2 профиля).
- Отчёты HTML / PDF / JSON «до/после».

## Явно НЕ входит
CVE-сканер, установка обновлений ОС, IPS-режим Suricata, SIEM/EDR, Windows, IPv6-правила, NAT/маршрутизация, multi-tenant SaaS, backup самого приложения, SBOM, нагрузочное тестирование 50 узлов, импорт CSV. Всё это — раздел ВКР «Перспективы развития».

## Стек
Python 3.12 · Django 5.2 LTS (templates + Bootstrap 5.3 + htmx, всё локально, без CDN) · PostgreSQL 16 · Redis 7 · Celery 5 (очереди `readonly` и `mutation`) · Gunicorn + Nginx · Docker Compose · Paramiko (SSH) · WeasyPrint (PDF) · Nmap, TShark (в контейнере worker) · pytest. Агент на узле — **только стандартная библиотека Python 3** (переносимость на Astra Linux).

## Поддерживаемые ОС узлов
Основная: Ubuntu Server 24.04 LTS. Совместимость агента через «ОС-профили» (`agent/nixfort_agent/osprofile.py`). Целевое расширение: Astra Linux SE 1.8 (Debian 12) — проверяется на финальном этапе, если позволит время.
