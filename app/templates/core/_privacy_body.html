Политика конфиденциальности

Редакция 1.0 от 28.10.2026

Оператором данных является организация, которая развернула приложение на своём контроллере. Данные хранятся только на этом контроллере (база PostgreSQL и каталог данных) и никуда не передаются: приложение не обращается к внешним сервисам, не подключает сторонние скрипты, шрифты или счётчики посещений.

1. Какие данные обрабатываются

  • Учётные записи: логин, хеш пароля (пароль в открытом виде не хранится), роли, время последнего входа.
  • Журнал действий: время, пользователь, действие, объект, итог и IP-адрес, с которого выполнено действие.
  • Сведения об узлах: имена, IP-адреса, версии ОС и пакетов, прослушиваемые порты, действующие настройки SSH, межсетевого экрана, Fail2ban и Suricata, отпечатки SSH-ключей узлов.
  • Журналы безопасности: число неудачных входов по SSH, сгруппированное по адресам источников и именам пользователей; пароли и полные строки журналов не сохраняются.
  • Записи трафика: только заголовки пакетов (первые 96 байт), без содержимого соединений; файл хранится под именем, равным его SHA-256.

2. Зачем

Данные нужны только для аудита и усиления защиты узлов проекта, для доказательной отчётности и для расследования действий пользователей. Для других целей они не используются.

3. Кто видит

Доступ определяется ролью и проектом: пользователь видит только проекты, на которые ему назначена роль. Скачать исходный файл записи трафика может только оператор или администратор; наблюдатель видит лишь результаты разбора.

4. Как защищены

Веб-интерфейс работает только по HTTPS. Сессия завершается после 30 минут бездействия. После 5 неудачных попыток вход под этим логином с того же адреса блокируется на 15 минут. Ключ контроллера и секреты хранятся вне базы, с доступом только для служебной учётной записи контейнера.

5. Cookie

Используются только две служебные cookie: идентификатор сессии и защита форм от подделки запросов (CSRF). Аналитических и рекламных cookie нет.

6. Сроки хранения

Сведения проекта хранятся, пока проект существует; при переносе проекта в архив они сохраняются для отчётности. Журнал действий не удаляется. Удаление учётной записи и данных проекта выполняет администратор контроллера по запросу.

7. Вопросы

По вопросам обработки данных обращайтесь к администратору приложения в вашей организации.
